Inicio

TaskList es un gestor de tareas desarrollado en JavaScript para el módulo de Desarrollo Web en Entorno Cliente (DWEC).

Permite añadir tareas, marcarlas como hechas, eliminarlas y filtrarlas. Todo se guarda en el navegador, sin necesidad de servidor.

Funcionalidades

  • Añadir y eliminar tareas
  • Marcar tareas como completadas
  • Filtrar por todas, pendientes o hechas
  • Contador de tareas pendientes
  • Persistencia con localStorage
